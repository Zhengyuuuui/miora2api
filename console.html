实测能力边界
6 种 type 全部实测跑通： text_to_image / image_to_image（6.7c）、 text_to_video / image_to_video（54c）、 text_to_3d / image_to_3d（11.52c）。 官方账单证实图生与文生同价（image 走独立键 image.edit，video/3d 只有 generate）。
参考图链路：GET /api/ai/cos/sts-tokens（30min）→ COS PUT → fileKey 喂给生成接口。 ⚠ 三种媒体参考图字段不同：image/3d 用 imageFileKeys[]，video 必须用 firstImageFileKey（首帧）且时长是 duration。
快速端点
GET  /v1/models                      # 41 模型，免登录
GET  /v1/tiers                       # 11 档 LLM（仅信息）
POST /admin/upload                   # 上传参考图 → fileKey
POST /v1/images/generations          # 同步等到 completed；stream:true 伪流式
POST /v1/videos/generations          # wait:false 异步入队
POST /v1/3d/generations              # 输出 GLB/FBX/STL/USDZ
GET  /v1/tasks/{id}                  # 进度 + 签名 URL
GET  /v1/media                       # 已存产物
GET  /v1/media/{id}/refresh          # 签名过期重签(3600s)
GET  /v1/costs                       # 成本矩阵
GET  /v1/stats                       # console 数据源
GET  /health
